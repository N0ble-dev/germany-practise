# Germany inspiration photos

The photographs in `public/images/germany/` are bundled local assets. The source credits and image-specific licenses below apply to the WebP versions as well. Each photograph was resized to 1600 pixels wide and converted to WebP. The interface uses `object-fit: cover`, which may crop the displayed frame. The scene content has not been changed.

These sources are Wikimedia Commons file pages. Image source credits and license links are also available under **Photo credits & licenses** on `/inspiration`, linked from the Today photo. Metadata from the Wikimedia API is recorded in `public/images/germany/credits.json`.

The dream-place choice and optional personal reason are part of the existing v2 learning snapshot. Older backups receive the default Berlin choice and an empty personal reason. Exported and optional cloud snapshots include both preferences. Reminders are shown in the app; the feature does not schedule push notifications or use an external photo feed.
