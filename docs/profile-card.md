# Profile learner card

The profile uses the [React Bits Lanyard TS-TW component](https://reactbits.dev/components/lanyard) from the [official registry JSON](https://reactbits.dev/r/Lanyard-TS-TW.json). The downloaded registry is retained in `docs/vendor/Lanyard-TS-TW.json` as source provenance. Its only dependency, `three@^0.180.0`, was already installed. `src/components/Lanyard.tsx` matches the formatted registry source with one React compatibility adjustment: the settings ref is updated in its existing effect instead of during rendering. Physics, materials, and pointer interactions remain from the registry.

`ProfileLanyard` loads the component on the client with `next/dynamic`; other study pages do not load Three.js. The stage is 600px tall, with the provided `frontImage`, `backImage`, and `strapImage` props. The local assets are `public/card-front.png`, `public/card-back.png`, and `public/band.png`; editable SVG originals sit beside them. The design follows the app's black, red, and gold identity.

The front texture is personalized in browser memory with the authenticated Google name, photo, and actual word/XP totals. `/api/profile/photo` checks the Neon session and loads that user's HTTPS Google-hosted image, making the photo available to canvas without cross-origin restrictions. It accepts no supplied image URL, rejects account mismatches, limits image size, and does not cache private responses. The personalized name and initials appear while the photo loads; missing or unavailable photos retain the initial. These generated textures are not added to browser backups, uploaded, or written to the database. Account changes unmount the card and cancel unfinished image work.

Front and Back buttons provide still views and keyboard access. Reduced-motion users get a still card automatically, and a static image remains available if WebGL fails. The decorative canvas is hidden from assistive technology; profile details and image descriptions remain available outside it. The registry pauses offscreen animation and disposes its renderer, textures, geometry, and event listeners on unmount.
